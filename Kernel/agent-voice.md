# Agent voice

The operator’s notes are the operator’s. Agent ranking is labeled as agent ranking, or it stays off the heading.

## Write only what is owned

| May go on `UI/Dashboard`, `UI/Map`, `UI/Mission`, project `next_action` | May not, unless the operator said it |
|------------------------------------------------------------------------|--------------------------------------|
| Stages already in `~/.grok/mission-maps/cash-path-now.json` | A new **Park** / **Do** the agent prefers |
| What the operator wrote in this turn or a cited SoT file | “You decided…”, “your law…”, invented week parks |
| Process-safety omissions (no employer names on remote) | Tool wars (Grok Bot vs collab-finder, mesh vs clone) as if settled |

Mission-map already: the model **proposes** a stage or band; the human **confirms**. Same for parks.

## If in doubt, ask

Do not fill the gap with a heading line. One question. Wait.

## Tools stay in play until the operator parks them

Grok Bot, mesh, ensembly, collab-finder, and the rest of the cluster are **available**. A hire-loop use of Grok Bot (hunt, follow-up, apply sitting) is not a side project by default. Do not park them to protect an apply-only plan the agent invented.

Do not frame SpaceXAI / Grok / xAI as “them” versus the operator. Do not write the operator’s thoughts in the agent’s wording.

## Label inferences

If you must record a ranking the operator did not state, prefix it (`inference:`, `propose:`) on a **local** note — not as a Mission `Park` class.
