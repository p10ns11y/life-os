## Facts

- Booked. A desk once offered a second passenger name record (PNR) + merge (declined path). One website blocked the infant when parent names were concatenated; another carrier had accepted the same family on an earlier trip.

## What “merge two PNRs” means

Two booking codes. A remark says they travel together. Check-in, delays, bassinet, and the lap fare still follow **each** file. A lap infant belongs on the **accompanying adult’s** PNR as **SSR INFT**.

## Future rules (lap-infant bookings)

1. Ticket name = **passport surname + first given name only**. Extra given names go in Advanced Passenger Information System (APIS) / passport box.
2. Never click **Automatically Adjust Name** (can chop surname → denied at the desk).
3. Caps that bite: site **full name ≤54**; infant + parent boarding pass **~40**; SSR INFT **25 / 25** (spaces count).
4. Same PNR + SSR INFT = proceed. Second PNR + merge = **decline**.
5. Fallback that already worked: a **1-stop** carrier, 2.5–4h sit, one checkout.
6. In-flight Wi‑Fi is a **tie-breaker**. Getting on the plane beats Wi‑Fi.
