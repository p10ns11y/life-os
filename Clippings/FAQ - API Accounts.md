## [If I already have an account for Grok, can I use the same account for API access?](#if-i-already-have-an-account-for-grok-can-i-use-the-same-account-for-api-access)

Yes, the account is shared between Grok and xAI API. You can manage the sign-in details at [https://accounts.x.ai](https://accounts.x.ai).

However, the billing is separate for Grok and xAI API. You can manage your billing for xAI API on [xAI Console](https://console.x.ai). To manage billing for Grok, visit [https://grok.com](https://grok.com) -> Settings -> Billing, or directly with Apple/Google if you made the purchase via Apple App Store or Google Play.
